# 🎮 digital-hunters-ui

A futuristic gaming studio landing page built using HTML & CSS.

This project was created as part of Assignment 3 from Cohort 3.0 by Sheryians Coding School while practicing advanced Flexbox layouts, CSS positioning, glassmorphism effects, neon aesthetics, and premium UI structuring concepts.

---

## 🚀 Features

- Futuristic Gaming UI
- Neon Glow Effects
- Glassmorphism Design
- Modern Hero Section
- Interactive Navigation
- Premium Project Cards
- Timeline / Process Section
- Hover Animations & Effects
- Clean Layout Composition

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Positioning
- Google Fonts
- Font Awesome
- Remix Icons

---

## 📚 Concepts Practiced

- display: flex
- position: relative
- position: absolute
- UI Structuring
- Glassmorphism
- Neon Styling
- Layering & Visual Hierarchy
- Alignment & Spacing
- Modern Landing Page Design
